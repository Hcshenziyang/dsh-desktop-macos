# Bundled Themes

每个子目录都是一套独立主题包：

- `theme.json`：版本化主题清单，包含完整浅/深配色、字体、动效、图标和壁纸参数。
- `wallpaper.png`：该主题独享的原创 16:10 静态素材。
- `CREDITS.md`：素材来源和生成提示词，便于后续公开发布与审计。

运行时只会读取校验通过的一级子目录。目录名必须与清单中的 `id` 一致；一个主题包不能引用
其他主题目录中的资源。用户自己导入的图片另存于 Application Support，不会写入这里。

当前 schema v3 的 `effects` 同时由 SwiftUI 与 WebKit 主题层读取，包含环境效果类型、运动
强度、控件圆角、玻璃模糊、图标语言、光晕强度，以及独立的 `frame` 框体语言。框体可定义
软边、霓虹、缝线、花影、诡箓、秘法双线、风化和像素硬边；新增效果必须兼容系统“减少动态效果”。

内置完整主题当前包括：星轨次元、留白秩序、云端软糖、海岬初晓、霓雨协议、猫耳心跳、
花火映像、诡箓迷城、龙焰秘典、灰烬王庭和方块晴野。人物与世界观素材均为本项目原创；
相近题材只保留氛围方向，不使用现实公众人物肖像或现有作品的角色、Logo 与提取纹理。
